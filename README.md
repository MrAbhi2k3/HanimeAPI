# Hanime API

A Hanime Scraper built using **FastAPI**.  
Explore the API documentation [here](https://haniapi.koyeb.app/docs).

## Features
- Fast and efficient scraping
- Comprehensive API endpoints
- Easy-to-use documentation

## Installation
```bash
git clone https://github.com/MrAbhi2k3/HanimeAPI.git
cd HanimeAPI
pip install -r requirements.txt
uvicorn main:app --reload
```
